# 🏋️ Fitness Workout Planner

A modern workout planning web application where users can explore exercises, add exercises to their daily plan, save favorite exercises, and track their workout statistics.

## 🛠️ Technologies Used

* **Next.js** – React framework for building the application
* **React** – Building reusable UI components
* **TypeScript** – Type-safe JavaScript development
* **Tailwind CSS** – Styling and responsive design
* **React Icons** – Icons used throughout the application
* **Context API** – Managing global application state

## ✨ Key Features

1. **Browse Exercises**
   Users can explore different exercises with information such as muscle groups, equipment, difficulty, duration, and calories.

2. **Create Today's Workout Plan**
   Users can add exercises to their daily workout plan and manage their selected exercises.

3. **Save Exercises**
   Users can save exercises for later and access them from the Saved section.

4. **Workout Statistics**
   The application displays the number of selected exercises, total workout duration, and total calories based on the active tab.

5. **Exercise Details & Navigation**
   Users can view detailed information about an exercise and navigate between workout, saved, and plan sections easily.
